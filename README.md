# Second Brain - Personal Knowledge Management System

A beautiful, modern web application for organizing your thoughts, notes, and tasks. Built with React, TypeScript, and Tailwind CSS, Second Brain provides a sleek alternative to Notion and Lunatask with enhanced aesthetics and personalization freedom.

## ✨ Features

### 📝 Rich Note-Taking
- **Rich Text Editor**: Powered by TipTap with markdown support
- **Tagging System**: Organize notes with custom tags
- **Pin Important Notes**: Keep frequently accessed notes at the top
- **Full-Text Search**: Quickly find any note by title, content, or tags

### ✅ Task Management
- **Priority Levels**: Organize tasks by low, medium, and high priority
- **Due Dates**: Set deadlines for your tasks
- **Tags & Categories**: Categorize tasks for better organization
- **Completion Tracking**: Mark tasks as complete with visual feedback

### 🎨 Aesthetic & Personalization
- **6 Beautiful Themes**: Ocean, Sunset, Forest, Lavender, Light, and Dark
- **Layout Options**: Switch between grid and list views
- **Font Size Control**: Choose from small, medium, or large text
- **Compact Mode**: Reduce spacing to see more content
- **Responsive Design**: Works seamlessly on all screen sizes

### 💾 Data Persistence
- **Local Storage**: All data is stored securely in your browser
- **No Server Required**: Complete privacy with offline functionality
- **Instant Sync**: Changes are saved immediately

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn package manager

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The app will be available at `http://localhost:5173`

## 🎯 Usage

### Creating Notes
1. Click the "New Note" button in the header or sidebar
2. Add a title and write your content using the rich text editor
3. Add tags to categorize your note
4. Click "Save Note" to store it

### Managing Tasks
1. Click "New Task" to create a task
2. Set the title, description, priority, and due date
3. Add tags for better organization
4. Check off tasks as you complete them

### Customizing Your Experience
1. Click the "Settings" button in the sidebar
2. Choose your preferred theme from 6 beautiful options
3. Adjust font size and layout preferences
4. Enable compact mode for denser content display

### Search & Filter
- Use the search bar to find notes and tasks by keywords
- Filter by view mode: All Items, Notes only, or Tasks only
- Search works across titles, content, and tags
